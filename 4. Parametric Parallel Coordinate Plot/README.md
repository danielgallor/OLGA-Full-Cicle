# Introduction 

This script visualises the processed results of a parametric study.

# Tutorial: Getting Started

**1. Required files**

You must have already pip intalled xgc

You must have installed the plotly module (pip install plotly)

To begin using this script, download the following files to your working folder:
- Parametric_Parallel_Coordinate_Plot.py
- Parametric_Parallel_Coordinate_Plot.json

You will also need:
- The processed results of the parametric study, in .csv format from Parametric_Post_Process.py.

**2. Input Data**

To add inputs into the calculation, open *Parametric_Post_Process.json*.
You will find the following code:

    { 
    "file_path":,
    "dataframe_read_file":,
    "output_filepath":,
    "output_name":
    
    }

This json formatting makes use of a dictionary structure {key:value} to take inputs in.

Each input key has the following meaning:

**file_path**
- This is the filepath where your processed results of the parametric study are. It does not need to be the same location as the Parametric_Post_Process python script.
- Note: when entering a file path into a json file, make sure to use two back slashes instead of one. e.g:

        file_path": "C:\\Users\\username\\python"

**dataframe_read_file**
- This is the name of the post process matrix .csv file generated by Parametric_Post_Process.py
- It tells the script which file to read. e.g.

        "dataframe_read_file":"Workflow_example_analysis",

**output_filepath**
- This is the filepath where your final parallel coordinate plot html file will be.
- e.g:

        "output_filepath": "C:\\Users\\username\\python"

**output_name**
- This is the name of the html file that contains the parallel coordinate plot. e.g.

        "output_name":"Workflow_example_analysis",


As an example, use the following inputs.


Note: for this example to work, you must have followed the steps in Genkey_Matrix_Generator, OLGA_Batch_Generator and Parametric_Post_Process readme files.

        { 
        "file_path":,
        "dataframe_read_file":"Workflow_example_analysis",
        "output_filepath":"C:\\Users\\agan.balangalibun\\Test",
        "output_name":"Worflow_example_Parallel_Coordinate_Plot"

        }

The pattern in the code above continues for a number of variables.

To break down these inputs:

        label = 'line Size (Inch)',

Refers to the label of the axis. It does not have to be the same as the column name which holds its data in the .csv file. It does have to be in string format, denoted by the quotation marks around it.

        # range = [],

Refers to the range of the axis. In this case, it is commented out (#) and left blank because of the autosizing programmed into this section. However, it can be turned on by uncommenting the line, and inserting range values in the square bracket. e.g. [0,100].

        # constraintrange = [,],

Refers to the bounds on the sliding bar on the axis. Usually, this is left the same as the range. As above, this input has left blank due to the autosizing that follows.

        range = [df['Gas Production Rate (MMscfd)'].min()-(df['Gas Production Rate (MMscfd)'].max() * 0.1),
                                        df['Gas Production Rate (MMscfd)'].max() * 1.1],

Refers to the range of the axis. In this case, it has been set up to auto range  with 10% on either side of the maximum and minimum values.
To change this to a different column, simple replace every instance of the column name with the column name of choice i.e. this part [df[**'Gas Production Rate (MMscfd)'**]

        constraintrange = [df['line Size (nominal Bore)Inch'].min() -(df['line Size (nominal Bore)Inch'].max() * 0.1),
                                                df['line Size (nominal Bore)Inch'].max() * 1.1],
Refers to the bounds on the sliding bar on the axis. As in the range above, values can be changed by changing the column names referenced.

        values = df['Gas Production Rate (MMscfd)']),

Refers to the values that are used to populate the axis. To change it, change the column name that is used in the dataframe call  df[**'Gas Production Rate (MMscfd)'**]). Note, for the purposes of this example, columns with numeric values will work here. It is possible to have text values, but that is beyond the scope of this tutorial. Refer to Plotly documentation for more information.

To add more columns, simply copy and paste the following into the script, making changes as necessary:

                                df['Gas Production Rate (MMscfd)'].max() * 1.1],

**Changing line colours**

It is possible to set the line colours in the parallel coordinate plot.

        line = dict(color = df['line Size (nominal Bore)Inch'],
                                                colorscale = [[0,'lightseagreen'],[1,'orange']],
                                                cmin= 10,
                                                cmax = 12,
In this example, the color of the lines is set by the 'line Size (nominal Bore)Inch' column. This column has values of 10 and 12. A scale of 0 to 1 is set with user defined colours.
The bounds of the colorscale is also set, with the minimum (corresponding to 0 on the colorscale) set to 10, and the maximum (corresponding to 1 on the colorscale) set to 12.


For further manipulation of the parallel coordinate plot, refer to official documentation on Plotly.
